**Owner:** Afronovation, Inc.

---

# 0. 🎯 DESIGN PHILOSOPHY

## Souvera is not a dashboard.

It is a:

* **decision terminal**
* **intelligence surface**
* **high-density interface for experts**

---

## Core Design Principle

> Every screen must reduce decision uncertainty.

---

## Design DNA

| Attribute   | Meaning                              |
| ----------- | ------------------------------------ |
| Dense       | High information per pixel           |
| Structured  | Clear hierarchy, never chaotic       |
| Fast        | No friction, minimal clicks          |
| Trustworthy | Source-aware, data-backed            |
| Controlled  | No visual noise                      |
| Scalable    | Works for 54+ countries, all modules |

# 7. ⚡ PERFORMANCE UX

---

## Requirements

* first paint < 1.5s
* API < 300ms
* lazy load heavy modules

---

## UX Handling

| Condition | Behavior               |
| --------- | ---------------------- |
| Loading   | skeleton UI            |

| Stale     | badge                  |

# 14. ❌ ANTI-PATTERNS (STRICTLY FORBIDDEN)

---

* oversized hero sections in terminal
* decorative gradients
* inconsistent spacing
* random colors
* UI that hides key data
* frontend-only access control
* duplicated components

---

# 15. 🎯 DESIGN GOVERNANCE RULE

---

## Every new component must answer:

1. What decision does this support?
2. What data powers it?
3. What happens if data is missing?
4. What happens if user lacks access?

If unclear → do not build
