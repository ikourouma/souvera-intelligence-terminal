## 1. Executive Summary & Core Value Proposition
The SOUVERA TRADE ANALYSIS module is an elite, Fortune 5-level global macro-intelligence platform designed to optimize supply chains and manage tariff risk across 54 African nations and 20 Caribbean countries/territories across 9 key industrial sectors.
## Core Analytical Modalities

* The AGOA/CBTPA Reauthorization Runway: Identifies strategic supply and demand gaps during the critical 6-month window before the December 31, 2026 legislative expiration. It highlights areas where U.S. exporters can fill African/Caribbean deficits, creating reciprocal trade arguments for policy lobbying.
* Post-AGOA Risk Mitigation Strategy: Programmatically adjusts if trade agreements are not reauthorized, recalculating immediate Most-Favored-Nation (MFN) tariff penalties ("Tariff Shock") and routing supply chains through alternative agreements like the African Continental Free Trade Area (AfCFTA), the UK Developing Countries Trading Scheme (DCTS), or the EU Everything But Arms (EBA) framework.

## 2. Global Sector & Macroeconomic Data Mapping
To ensure clean calculations across goods and services, all 9 primary sectors map directly to standardized international trade codes (HS Code classification for goods and BPM6/ISIC classification for service/infrastructure layers).
## Classification Reference Blueprint

   1. Technology and Software: BPM6 SI (Telecommunications, computer, and information services)
   2. Agriculture and Food Processing: HS 01–24 (Raw and processed foods)
   3. Energy and Power: HS 27 (Crude, refined petroleum, gas, electricity infrastructure)
   4. Manufacturing and Textiles: HS 50–63 (Textiles/Apparel) & HS 84–85 (Machinery/Electronics)
   5. Mining and Natural Resources: HS 25–26 (Ores/Minerals) & HS 71 (Precious stones/Gold)
   6. Tourism and Hospitality: BPM6 SD (International travel services)
   7. Logistics and Trade: BPM6 SF (Transport services) + World Bank Logistics Performance Index (LPI)
   8. Digital Infrastructure: ITU Data (Broadband density) + ISIC Section J (Information & Communication)
   9. Fintech and Digital Finance: BPM6 SG (Financial services) + World Bank Findex Indicators

import osimport hashlibimport jsonimport requestsfrom decimal import Decimalfrom datetime import datetimeimport google.generativeai as genai

class SouveraBackendEngine:
    """
    SOUVERA CORE DATA & INSIGHT ENGINE
    Orchestrates live global clearinghouse ingestion, caching, and AI insights.
    """
    def __init__(self):
        self.comtrade_url = "https://un.org"

    def fetch_live_un_comtrade(self, reporter: str, partner: str, hs_code: str, token: str) -> dict:
        """Queries live asymmetric trade values directly from UN Comtrade v1."""
        headers = {"Ocp-Apim-Subscription-Key": token}
        params = {"reporterCode": reporter, "partnerCode": partner, "cmdCode": hs_code, "flowCode": "M,X"}
        try:
            res = requests.get(self.comtrade_url, headers=headers, params=params, timeout=10)
            return res.json() if res.status_code == 200 else {}
        except requests.exceptions.RequestException:
            return {}

    @staticmethod
    def generate_cache_key(country: str, sector: str, agoa_active: bool) -> str:
        """Generates an immutable md5 string signature for secure dashboard caching."""
        current_period = datetime.now().strftime("%Y-%m")
        raw_string = f"{country.lower()}_{sector.lower()}_{current_period}_{str(agoa_active)}"
        return hashlib.md5(raw_string.encode('utf-8')).hexdigest()

    def run_souvera_trade_analysis(
        self, country_iso3: str, sector_title: str, net_position_m: float, region: str, agoa_active: bool = False
    ) -> str:
        """
        SOUVERA TRADE ANALYSIS - Multi-Scenario Prompt Pipeline
        Injects real-world policy constraints directly into Gemini 2.5 Flash system instructions.
        """
        trade_act = "AGOA" if region == "Africa" else "CBTPA"
        states_list = ", ".join(US_STATE_SPECIALIZATIONS.get(sector_title.lower(), ["Primary US Manufacturers"]))
        
        # Enforce distinct personas depending on whether preferential trade acts are active
        if agoa_active:
            system_instruction = (
                "You are SOUVERA TRADE ANALYSIS, an elite Fortune 5 corporate trade strategist. "
                "Current timeline context is June 2026. Unilateral preferences are active but expire "
                "on December 31, 2026. Your tone is urgent, objective, and authoritative. "
                f"You MUST emphasize that exactly 6 months remain until the {trade_act} cliff to "
                "force immediate procurement decisions."
            )
            prompt = f"Analyze market for {country_iso3} in {sector_title} with a position of ${net_position_m}M. Tie to {states_list} exports."
        else:
            system_instruction = (
                "You are SOUVERA TRADE ANALYSIS, operating in a post-AGOA regulatory landscape. "
                "Unilateral U.S. preferences have expired. Your tone is defensive and risk-mitigating. "
                "Focus entirely on calculating tariff shock mitigation, alternative bilateral frameworks, "

        model = genai.GenerativeModel(
            model_name='gemini-2.5-flash',
            system_instruction=system_instruction
        )
        
        response = model.generate_content(prompt)
        return response.text.strip()

import unittestfrom decimal import Decimal
class TestSouveraPipelineCalculations(unittest.TestCase):
    
    def test_regional_value_content_formula(self):
        """Verifies mathematical calculation of Transaction Value metrics."""
        export_val = Decimal('100000.00')
        foreign_inputs = Decimal('60000.00') # Local value add = 40%
        
        rvc_pct = ((export_val - foreign_inputs) / export_val) * 100
        self.assertEqual(rvc_pct.quantize(Decimal('0.01')), Decimal('40.00'))

    def test_de_minimis_exception_handling(self):
        """Validates that a cargo shipment is safely approved if its foreign components do not cross the 7% threshold."""
        export_val = Decimal('500000.00')
        foreign_inputs = Decimal('20000.00') # Accounts for exactly 4.0% of product value
        de_minimis_allowance_cap = 7.00

## 8. Implementation & Deployment Recommendations
To maintain high stability and data confidentiality across the SOUVERA architecture, ensure your engineering leadership adheres to these three production deployment rules:

   1. Enforce Row-Level Security (RLS) on User Workspaces: Since clients will upload proprietary capital exposure vectors and supply chain profiles into workspace_monitored_vectors, enable Postgres RLS. Ensure that a user's org_id token is cryptographically validated against every query to isolate tenant environments.
   2. Streamline Frontend State via Server Actions: In Next.js, leverage Server Actions to fetch cached AI insights or trigger report exports. This architecture protects your backend API tokens and keeps the client bundle light.
   3. Deploy Circuit Breakers around Clearinghouse API Connectors: External APIs like UN Comtrade occasionally go down for maintenance. Wrap your harvesting classes in a circuit breaker pattern (such as pybreaker in Python). If external servers encounter downtime, the system should fail gracefully, serving the last cached database metrics and displaying a small message banner: Data Purity Layer: Cached Mode Active.
