# 🧠 **Souvera × AfDEC Integration Spec v1.0**

**Owner:** Afronovation, Inc.
**Platforms:**

* **Souvera Intelligence Terminal (SIT)**
* **AfDEC (North Carolina African Diaspora Economic Council)**

**Purpose:**
Define **strict technical, product, and branding boundaries** between Souvera and AfDEC, while enabling **seamless integration and conversion**.

---

# 1. 🎯 STRATEGIC POSITIONING

---

## 1.1 Platform Roles

| Entity      | Role                                                    |
| ----------- | ------------------------------------------------------- |
| **Souvera** | Intelligence platform (product, SaaS, monetization)     |
| **AfDEC**   | Economic organization (policy, community, distribution) |

---

## 1.2 Core Principle

> AfDEC uses Souvera.
> AfDEC does not replicate or own Souvera.

---

## 1.3 Outcome

* Souvera = scalable SaaS
* AfDEC = trusted gateway + demand generator

---

# 2. 🧭 INTEGRATION MODEL

---

## Architecture

```text
AfDEC Website
     ↓
Souvera Lite APIs
     ↓
Souvera Platform (Full Terminal)
```

---

## Data Flow

* AfDEC → consumes Souvera-lite APIs
* Souvera → remains the source of truth

---

# 3. 🔌 ALLOWED API INTEGRATION

---

## 3.1 AfDEC Allowed Endpoints

| Endpoint                 | Purpose            |
| ------------------------ | ------------------ |
| `/api/v1/countries-lite` | map rendering      |
| `/api/v1/country-lite`   | country teaser     |
| `/api/v1/compare-lite`   | comparison preview |
| `/api/v1/insight-teaser` | narrative insight  |

---

## 3.2 Access Level

* Public-level data only
* No authentication required
* Rate-limited

---

## 3.3 Data Scope

Allowed:

* country identity
* GDP, population, GDP growth
* signal label
* teaser narrative
* sector highlights

---

## 3.4 Forbidden

AfDEC must NOT access:

* `/api/v1/country`
* `/api/v1/trade`
* `/api/v1/series`
* `/api/v1/reports`
* `/api/v1/enterprise/*`

---

# 4. 🔐 DATA GOVERNANCE RULES

---

## 4.1 Source of Truth

👉 All intelligence must come from Souvera APIs

---

## 4.2 No Data Duplication

AfDEC must not:

* store Souvera datasets permanently
* rebuild intelligence logic
* calculate signals

---

## 4.3 Cache Policy

AfDEC may:

* cache responses temporarily (CDN)

AfDEC may NOT:

* maintain independent data stores

---
