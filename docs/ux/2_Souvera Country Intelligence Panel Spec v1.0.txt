# 1. 🎯 PURPOSE

The Country Intelligence Panel is:

👉 **The single source of truth for country-level decision-making**

It must allow a user to answer in < 60 seconds:

* Is this market attractive?
* What is driving growth?
* What are the risks?
* Where are the opportunities?
* Should I act?

# 9. 🧠 ENTITLEMENT LOGIC (CRITICAL)

---

## Rule

👉 UI never decides access


```ts

  hideTradeTab()
}
```
