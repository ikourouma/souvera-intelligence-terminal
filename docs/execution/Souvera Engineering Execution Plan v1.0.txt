# 2. 🏗️ REPOSITORY STRUCTURE (MANDATORY)

## 🔷 Monorepo (recommended)

```
/souvera
  /apps
    /terminal-web        → Next.js (user-facing terminal)
    /admin-console       → Next.js (admin/internal)
    /api-gateway         → Next.js / Edge (API layer)
  
  /packages
    /ui                  → shadcn components (shared)
    /config              → env, constants
    /types               → TS types
    /auth                → auth utilities
    /entitlements        → access logic
    /api-client          → fetch wrappers
    /utils               → helpers
  
  /services
    /ingestion           → edge functions / cron jobs
    /signal-engine       → scoring logic
    /normalization       → data transforms
  
  /infra
    /supabase            → SQL, RLS, seeds
    /vercel              → deployment configs
  
  /docs
    /prd
    /trd
    /sql-pack
    /api-binding
    /route-spec
    /execution-plan
```

## Structure

```

  worldbank.ts
  imf.ts
  oecd.ts
  comtrade.ts
  gdelt.ts
  oxr.ts
  restcountries.ts
```

---

## Each ingestion must:

1. fetch
2. transform
3. normalize
4. insert into DB
5. log into:

   * `souvera_ingestion_jobs`
   * `souvera_source_payload_archive`
   * `souvera_source_health`

---

## CRON Setup
