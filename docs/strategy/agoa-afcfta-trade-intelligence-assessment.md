## Executive Summary

The convergence of AGOA reauthorization uncertainty and AfCFTA implementation creates an unprecedented opportunity for Souvera to serve as the authoritative evidence platform for U.S.–Africa trade governance, policy modernization, and investment intelligence.

### The Opportunity

With AGOA's temporary reauthorization through December 31, 2026, and the USTR's active modernization consultation (comments due May 15, 2026), there is immediate demand for:

1. **Evidence-Based Policy Support** — Structured intelligence on country eligibility, sector performance, and market access barriers
2. **Supply-Demand Matching** — Connecting African production capacity with U.S. market requirements
3. **AfCFTA Alignment** — Understanding how continental integration affects bilateral trade preferences
4. **Product-Level Intelligence** — HS code-level analysis of export opportunities and competitive positioning

### Strategic Recommendation

**Souvera should develop an AGOA + AfCFTA Trade Intelligence Module** that positions the platform as the authoritative decision-support tool for:
- U.S. Chamber of Commerce and trade associations
- USTR and U.S. trade policymakers
- African governments and trade ministries
- Development finance institutions (DFC, IFC, AfDB)
- Institutional investors evaluating African supply chains

**Implementation Recommendation:** Begin MVP in Phase 4B, expand in Phase 4C

## 3. AfCFTA Alignment Context

### 3.1 AfCFTA Overview

The African Continental Free Trade Area aims to:
- Create a single continental market for goods and services
- Achieve free movement of business persons and investments
- Establish a continental customs union
- Deepen economic integration of Africa

**Implementation Status:**
- Agreement entered into force: May 30, 2019
- Trading under AfCFTA: January 1, 2021
- Current phase: Implementation of Phase I protocols (Trade in Goods, Trade in Services, Dispute Settlement)
- Ongoing: Negotiations on Phase II protocols (Investment, Intellectual Property, Competition, Digital Trade)

**Source:** [Citation needed — AfCFTA Secretariat]

### 3.2 U.S.–AfCFTA Cooperation Framework

The U.S. has identified cooperation areas with AfCFTA:

1. **Infrastructure** — Transportation, energy, digital
2. **Digital Trade** — E-commerce, data flows, digital standards
3. **Agro-processing** — Food security, value chains
4. **Pharmaceuticals** — Local manufacturing, medical devices
5. **Automobiles** — Regional automotive value chains
6. **Transportation Systems** — Logistics, ports, corridors
7. **Logistics Services** — Supply chain efficiency

**Source:** [Citation needed — U.S. State Department, USTR announcements]

### 3.3 AGOA–AfCFTA Interaction

**Key Questions for Policy:**
- How do AGOA preferences interact with AfCFTA rules of origin?
- Can regional cumulation under AfCFTA count toward AGOA eligibility?
- How should AGOA modernization align with AfCFTA tariff schedules?
- What is the pathway for non-AGOA African countries (North Africa)?

**Souvera Opportunity:**
Provide intelligence on how AfCFTA implementation affects U.S. market access opportunities for African products, and how regional value chains can optimize both AGOA and AfCFTA benefits.

### 6.4 Matching Algorithm Concept

**Opportunity Score = f(Supply Capacity, Demand Gap, Market Access, Risk Adjustment)**

Components:
1. **Supply Capacity Score** (0-100): Production capacity, quality, export readiness
2. **Demand Gap Score** (0-100): U.S. import growth, supplier concentration, diversification priority
3. **Market Access Score** (0-100): AGOA eligibility, tariff advantage, NTB assessment
4. **Risk Adjustment** (-50 to 0): Governance risk, logistics risk, compliance risk

**Output:** Country-Product opportunity ranking with supporting evidence

## 8. Country-Sector-Product Scoring Model

### 8.1 Multi-Dimensional Scoring Framework

```
┌─────────────────────────────────────────────────────────────┐
│                 SCORING DIMENSIONS                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  COUNTRY SCORE              SECTOR SCORE                    │
│  ├─ AGOA Eligibility (Y/N)  ├─ Sector Strength (0-100)     │
│  ├─ AfCFTA Status           ├─ Growth Potential (0-100)    │
│  ├─ Governance (0-100)      ├─ Investment Climate (0-100)  │
│  ├─ Infrastructure (0-100)  ├─ Export Readiness (0-100)    │
│  └─ Risk Profile            └─ Competitive Position        │
│                                                             │
│  PRODUCT SCORE              MARKET ACCESS SCORE             │
│  ├─ Export Capacity (0-100) ├─ Tariff Advantage (0-100)    │
│  ├─ Quality Standards       ├─ NTB Assessment              │
│  ├─ Competitive Price       ├─ Compliance Status           │
│  └─ Supply Chain Position   └─ Rules of Origin             │
│                                                             │
│  DEMAND ALIGNMENT SCORE                                     │
│  ├─ U.S. Import Growth                                      │
│  ├─ Supplier Diversification Need                           │
│  ├─ Critical Minerals Priority                              │
│  └─ Friend-shoring Alignment                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
              ┌───────────────────────────────┐
              │    COMPOSITE OPPORTUNITY      │
              │          SCORE                │
              │    (Weighted Aggregation)     │
              └───────────────────────────────┘
```

### 8.2 Scoring Methodology

**Step 1: Normalize Indicators**
- Transform all indicators to 0-100 scale
- Handle missing data with conservative defaults
- Apply source confidence weighting

**Step 2: Dimension Weights**
```
Country Score Weight:      20%
Sector Score Weight:       25%
Product Score Weight:      25%
Market Access Weight:      15%
Demand Alignment Weight:   15%
```

**Step 3: Risk Adjustment**
- Governance risk: -10 to 0
- Logistics risk: -10 to 0
- Compliance risk: -10 to 0
- Political risk: -10 to 0

**Step 4: Composite Score**
```
Opportunity Score = (Weighted Dimension Sum) + (Risk Adjustment)
Range: 0-100 (after adjustment, floor at 0)
```

### 8.3 Score Interpretation

| Score Range | Interpretation | Action |
|-------------|---------------|--------|
| 80-100 | High Opportunity | Priority for investment promotion |
| 60-79 | Moderate Opportunity | Targeted development support |
| 40-59 | Emerging Opportunity | Infrastructure/capacity building focus |
| 20-39 | Limited Opportunity | Long-term development |
| 0-19 | Not Currently Viable | Monitor for changes |

## 14. Risks and Guardrails

### 14.1 Data Quality Risks

| Risk | Mitigation |
|------|------------|
| Source data gaps | Conservative defaults, missing data indicators |
| Outdated data | Data freshness badges, staleness alerts |
| Conflicting sources | Source priority rules, admin override |
| Incorrect transformations | Validation rules, manual review workflow |

### 14.2 Policy/Legal Risks

| Risk | Mitigation |
|------|------------|
| Unauthorized policy claims | Evidence-based framing, no advocacy |
| Incorrect eligibility information | Source attribution, "verify with USTR" disclaimers |
| Commercial sensitivity | Access controls, enterprise licensing |
| Data licensing restrictions | License compliance, source registry |

### 14.3 Operational Risks

| Risk | Mitigation |
|------|------------|
| Source API changes | Error monitoring, fallback procedures |
| Data volume growth | Scalable architecture, archival strategy |
| Admin errors | Validation rules, publish workflow, audit log |
| Performance degradation | Caching, query optimization |

### 14.4 Guardrails

**Content Guardrails:**
- No unsupported numeric claims
- Source attribution required
- "Data pending" for missing fields
- No political advocacy language
- Evidence-based framing only

**Process Guardrails:**
- Admin review before publish
- Validation before ingestion
- Audit logging for all changes
- Role-based access enforcement

## 16. Recommendation

### 16.1 Strategic Recommendation

**Souvera should implement an AGOA + AfCFTA Trade Intelligence Module** beginning in Phase 4B, with full product-level intelligence in Phase 4C.

**Rationale:**
1. **Timing Alignment** — AGOA modernization debate is active (comments due May 15, 2026)
2. **Competitive Differentiation** — No comparable integrated platform exists
3. **Revenue Potential** — High-value enterprise use cases (Chamber, DFIs, trade ministries)
4. **Foundation Leverage** — Builds on existing 74-market, 7-sector coverage
5. **Phase 4B Synergy** — Source Registry and Indicator Builder benefit all use cases

### 16.2 MVP Scope Recommendation

1. Source Registry (admin source configuration)
