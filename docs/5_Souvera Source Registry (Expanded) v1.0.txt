# 🧠 **Souvera Source Registry (Expanded) v1.0**

**Owner:** Afronovation, Inc.
**Product:** Souvera Intelligence Terminal
**Purpose:** Operational control of all data sources powering Souvera
**Scope:** APIs, ingestion, ownership, SLA, cost, fallback, compliance

---

# 1. 🎯 OBJECTIVE

Provide a **single authoritative registry** that defines:

* what data sources are used
* how they are accessed
* who owns them
* how often they refresh
* what happens if they fail
* how they are legally used

---

# 2. 🧭 DESIGN PRINCIPLE

> No data enters Souvera unless it exists in this registry.

---

# 3. 📊 SOURCE REGISTRY STRUCTURE

Each source must define:

| Field               | Description               |
| ------------------- | ------------------------- |
| Source Key          | Unique identifier         |
| Name                | Provider name             |
| Domain              | Data domain               |
| API Base URL        | Primary endpoint          |
| Docs URL            | Documentation             |
| Auth Model          | API key / public / OAuth  |
| Data Type           | Open / Licensed / Premium |
| Refresh Cadence     | Expected update frequency |
| SLA Tier            | Reliability level         |
| Priority Rank       | Source selection priority |
| Fallback Sources    | Backup providers          |
| Cost Tier           | Free / Paid               |
| Legal Status        | Approved / Review         |
| Redistribution Rule | Allowed / Restricted      |
| Owner               | Responsible team          |
| Status              | Active / Paused / Retired |
