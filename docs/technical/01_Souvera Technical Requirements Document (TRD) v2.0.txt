# 2. 🏗️ SYSTEM ARCHITECTURE

---

## 2.1 High-Level Architecture

```text
External Data Sources
        ↓
Ingestion Services (Edge Functions / CRON)
        ↓
Normalization Layer
        ↓
Supabase Database (Source of Truth)
        ↓
API Gateway (Next.js / Edge)
        ↓
Frontend Applications (Terminal / Admin / AfDEC-lite)
```

---

## 2.2 Core Layers

| Layer        | Responsibility                 |
| ------------ | ------------------------------ |
| Data Sources | External providers             |
| Ingestion    | Fetch + normalize              |
| Storage      | Central database               |
| API          | Access + entitlement filtering |
| UI           | User interaction               |
